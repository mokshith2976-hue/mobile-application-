# Smart Krishi — Android App Implementation Prompt
### For Google AI Studio (Gemini API) · Android / Kotlin / Jetpack Compose

---

## 🎯 Project Overview

Build **Smart Krishi**, a bilingual (Kannada + English) AI-powered farming assistant Android app targeting small and medium farmers in Kodagu district, Karnataka, India. The app helps farmers with real-time weather, crop market prices, irrigation advice, fertilizer schedules, AI-powered disease detection from leaf photos, and a conversational AI farming advisor.

---

### 5. 💧 Irrigation Advisor Screen

**Purpose:** Calculate irrigation need using FAO-56 water balance method.

**UI Components:**
- Form card with inputs:
  - **Crop Type** dropdown (Coffee Arabica/Robusta, Pepper, Banana, Arecanut, Coconut)
  - **Farm Area** (acres, number input)
  - **Days Since Last Irrigation** (number)
  - **Rainfall Last 7 Days** (mm)
- **"Calculate Irrigation Need"** primary button
- **Result Card** (green gradient) showing:
  - Irrigate / Skip recommendation
  - Volume in litres and duration in minutes
  - Duration for sprinkler at 78% efficiency

**Calculation Logic (FAO-56):**
```kotlin
fun calcIrrigation(crop: String, acres: Double, daysSince: Int, rain7d: Double): IrrigationResult {
    val cropEtc = mapOf(
        "coffee_arabica" to 4.5,  // mm/day
        "pepper" to 3.8,
        "banana" to 6.2,
        "arecanut" to 4.0,
        "coconut" to 3.5
    )
    val etc = cropEtc[crop] ?: 4.0
    val totalEt = etc * daysSince
    val effectiveRain = rain7d * 0.75
    val deficit = totalEt - effectiveRain
    val irrigate = deficit > 10.0
    val litresPerAcre = if (irrigate) deficit * 4046.86 / 1000 else 0.0
    val totalLitres = litresPerAcre * acres
    val minutesAtEfficiency = (totalLitres / (12.5 * 60 * 0.78)) * 60 // sprinkler @ 12.5 L/min
    return IrrigationResult(irrigate, totalLitres, minutesAtEfficiency.toInt())
}
```

```kotlin
suspend fun analyzeLeafDisease(imageBitmap: Bitmap): DiseaseResult {
    val model = GenerativeModel(
        modelName = "gemini-1.5-flash",
        apiKey = BuildConfig.GEMINI_API_KEY
    )
    
    val prompt = """
        You are an expert agricultural plant pathologist specializing in Kodagu, Karnataka crops.
        Analyze this leaf image and identify any disease or health condition.
        
        Respond in this exact JSON format:
        {
          "disease_name": "Name of disease or 'Healthy'",
          "confidence": 0.0 to 1.0,
          "severity": "none|mild|moderate|severe",
          "affected_crop": "coffee|pepper|banana|arecanut|coconut|unknown",
          "symptoms": "Brief description of observed symptoms",
          "cause": "Pathogen or cause",
          "treatment": {
            "organic": "Organic treatment option",
            "chemical": "Chemical treatment with dosage",
            "preventive": "Prevention measures"
          },
          "urgency": "monitor|act_soon|urgent"
        }
        
        Be specific about Kodagu region conditions (high humidity, monsoon climate).
        If image is unclear or not a plant leaf, say so in disease_name.
    """.trimIndent()
    
    val imageContent = content {
        image(imageBitmap)
        text(prompt)
    }
    
    val response = model.generateContent(imageContent)
    return parseJson<DiseaseResult>(response.text!!)
}
```

    5. For price advice, always add a disclaimer: "Verify with local APMC before selling"

**Chat Implementation:**
```kotlin
class GeminiChatManager(private val apiKey: String) {
    private val model = GenerativeModel(
        modelName = "gemini-1.5-flash",
        apiKey = apiKey,
        systemInstruction = content { text(systemPrompt) }
    )
    private val chat = model.startChat(history = emptyList())
    
    suspend fun sendMessage(userMessage: String): String {
        val response = chat.sendMessage(userMessage)
        return response.text ?: "Sorry, I could not generate a response."
    }
}
```
